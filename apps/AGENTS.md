# Mobile apps

Read `../.mobile-apps/WORKFLOW.md` before creating, editing, publishing, or rolling back an app here.

Keep each app in its existing directory and permanent URL. Prefer one authored `index.html`; the manifest, service worker, icons, and release inventory are generated support files. Check locally before committing to `master`. Normal requested edits are authorized for direct save and publication, subject to actual tool permissions. Never create a pull request for this workflow. Never bypass branch protection or tool approval.

Do not change the repository's root homepage as part of this workflow.
